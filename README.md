# Boolean Math Game

A Java Swing-based educational game that challenges players with mathematical and Boolean logic questions through an interactive graphical user interface.

## Features

- Interactive GUI built with Java Swing
- Score tracking system
- Leaderboard functionality
- Timer-based gameplay
- Mathematical and Boolean logic challenges

## Technologies Used

- Java
- Java Swing
- Collections Framework

## How to Run

1. Open the project in NetBeans IDE.
2. Build the project.
3. Run `BooleanMathGameGUI.java`.
4. Start playing and track your score on the leaderboard.
